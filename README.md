# Guitarino — statyczna strona

Strona nie korzysta z WordPressa ani innego CMS-a. Otwórz `index.html` bezpośrednio w przeglądarce albo opublikuj plik razem z folderem `assets` na hostingu statycznym.

Zdjęcia i mapa w `assets/` pochodzą z obecnej strony Guitarino. Google Fonts jest opcjonalne — przy braku połączenia strona używa czcionek systemowych.
